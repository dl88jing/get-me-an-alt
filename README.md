# Get Me An Alt

Paste a link or photo of any pricey gadget. A team of Gemini 4 Argon agents researches it and hands you a DIY alternative:
a bill of materials from mainstream retailers, plate-optimized 3D print files for your printer, IKEA-style animated
assembly instructions, and an interactive exploded 3D view.

Built at the Gemini 4 Argon SF Hackathon (Oct 25, 2026). See `AGENTS.md` for the full spec.
